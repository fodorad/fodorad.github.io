Personality Questionnaire

Administer, score and record validated personality and affect questionnaires

GitHub PyPI Docs

What this is

Collecting validated self-reports is the unglamorous half of an affective-computing pipeline. This started as a small helper for scoring BFI-2 and VAS-F responses in one experiment; it is now a full data-collection application, built around one idea: an instrument is data, not code. Items, response ranges, subscale membership and reverse keys are declared as values, and a single vectorised scorer turns responses into scores without knowing which questionnaire it is holding. Adding an instrument adds no arithmetic.

The application

Beyond the Python API and CLI, pq ui serves a local data-collection application with five tabs: an overview, participant setup, the questionnaire itself — rendered as the authors published it, radio buttons with the labelled response scale, sliders for visual-analogue items — the computed scores, and every record collected so far with filters and export. It binds to 127.0.0.1 and makes no outbound request: participant self-reports are consent-restricted, and a tool that cannot be reached from another machine is the honest default for that kind of data. Two browser tabs are two independent participants, so one machine runs two stations side by side.

Data-driven instruments
  • Items, subscales and reverse keys are declared as Python literals, checked by the type checker and validated at import.
  • Reverse-keying belongs to the subscale, not the item, folded into a signed weight matrix.
  • Every subscale carries a higher_is polarity, so nothing has to be inferred from a name.
Provenance & storage
  • Every record carries the package version, git SHA, and instrument hash it was scored with.
  • A SQLAlchemy record store, configurable via PQ_DATABASE_URL.
  • Export as wide CSV, long CSV, or archival JSON — from the CLI or the Records tab.
Engineering practice
  • 97% test coverage, enforced in CI by Codecov.
  • GitHub Actions CI, release-please-driven versioning, and published Sphinx docs.
  • Deprecated a CSV-based instrument format that was never actually read by any code path — and had a misspelled subscale name to prove it.
Related work
  • PersonalityLinMulT predicts perceived Big Five traits from video; this package collects the self-reported ground truth on the same [0, 1] scale.
  • The two are deliberately uncoupled in code — this package has no ML dependencies.
  • An exported BFI-2 record drops straight into a self-report-versus-perception comparison.

Try it

pip install "personality_questionnaire[ui]"
pq ui                      # http://127.0.0.1:8080

Or from the command line directly:

pq list                                  # what is available
pq info bfi2                             # items, subscales, citation
pq run bfi2 --participant P01            # ask, score, and store
pq score bfi2 --input answers.csv        # score a file
pq export --shape long --output study-a.csv

Nothing here encrypts the database.


Securing the machine the application runs on is the operator's responsibility. Stack: Python 3.12+, SQLAlchemy, MIT licensed.
